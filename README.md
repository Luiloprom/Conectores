## Ejercicio a realizar
- Se pide implementar hibernate en el ejercicio de conectores ya realizado.

## Solución implementada
- En mi caso es el mismo codigo y todo lo unico que la parte de Oracle la he sustituido por hibernate.
- El unico problema que he tenido a sido al poner la ruta del archivo de configuracion que se ponia mal pero por lo demas todo bien.
- En el diagrama UML seria remplazar los DAO por hibernate.
- Y en mi caso he hecho el mapeo mediante anotaciones en las clases ya que me parece mas comodo.

## Requisitos para lanzar el programa 
- Tener instalado Docker.
- Lanzar Docker desde consola con: `docker compose up -d`.
- Ejecutar la `App`.
